# PunjabState News (पंजाब स्टेट न्यूज़) 📰

पंजाब के सभी 23 ज़िलों की ताज़ा खबरें स्वतः (अपने-आप) फेच करने वाला पूर्णतः स्वचालित (Fully Automated) Python न्यूज़ पोर्टल।

---

## 🌟 प्रमुख विशेषताएँ (Key Features)

1. **ऑटोमैटिक 24x7 न्यूज़ फेचर (Auto-Fetcher Engine):**
   * पंजाब के सभी 23 ज़िलों (*Ludhiana, Amritsar, Jalandhar, Patiala, Bathinda, Mohali, Hoshiarpur, Pathankot, Moga, Firozpur* आदि) से गूगल न्यूज़ और प्रमुख पोर्टल्स की RSS फ़ीड से खबरें अपने-आप लाता है।
   * डुप्लीकेट खबरों को अपने-आप फ़िल्टर करता है ताकि एक ही खबर बार-बार पोस्ट न हो।

2. **स्मार्ट AI री-राइटर एवं SEO ऑप्टिमाइज़ेशन (Google Ranking Safe):**
   * RSS से सिर्फ मुख्य फैक्ट्स लेता है और हेडलाइन व कंटेंट को नए आकर्षक रूप में री-राइट करता है।
   * हर खबर के लिए 3-4 बुलेट पॉइंट्स में **त्वरित सारांश (Quick Highlights)** तैयार करता है।
   * **Google NewsArticle JSON-LD Schema Markup** एम्बेड किया गया है जिससे साइट Google News और Google Discover में रैंक करे।

3. **आधुनिक और रिस्पॉन्सिव न्यूज़ पोर्टल (UI/UX):**
   * मोबाइल, टैबलेट और डेस्कटॉप सभी पर सुपर-फास्ट।
   * लाइव ब्रेकिंग न्यूज़ टिकर पट्टी।
   * ज़िला अनुसार फ़िल्टर (City Tabs & District Dropdown)।
   * 1-क्लिक **WhatsApp शेयर बटन**।

4. **मोनेटाइजेशन एवं कमाई के स्लॉट्स (Monetization Ready):**
   * हेडर बैनर (728x90) - IELTS / वीज़ा कंसल्टेंट्स के लिए
   * साइडबार बैनर (300x500) - लोकल बिल्डर्स / प्रॉपर्टी डीलर्स के लिए
   * इन-आर्टिकल बैनर - खबरों के बीच में
   * एडमिन पैनल से सीधे विज्ञापन का लिंक और फोटो बदलने की सुविधा।

5. **शक्तिशाली एडमिन डैशबोर्ड (Admin Dashboard):**
   * कुल खबरों, पेजव्यूज और ज़िलों का लाइव स्टेटस।
   * एक क्लिक में नई खबरें फेच करने का बटन (**Fetch Now**)।
   * खुद से कोई विशेष ब्रेकिंग न्यूज़ पोस्ट करने का फॉर्म।

## 🚀 वेबसाइट कैसे चलाएं? (How to Run)

### 1. फोल्डर में जाएं:
```bash
cd "C:\Users\admin\Downloads\punjabstate"
```

### 2. वेबसाइट शुरू करें:
```bash
python run.py
```

### 3. ब्राउज़र में खोलें:
* **न्यूज़ पोर्टल:** [http://localhost:8000](http://localhost:8000)
* **एडमिन पैनल:** [http://localhost:8000/admin](http://localhost:8000/admin)

## 📁 प्रोजेक्ट स्ट्रक्चर (File Structure)

```
punjabstate/
├── config.py              # 23 ज़िलों की सूची, श्रेणियां और सेटिंग्स
├── database.py            # SQLite डेटाबेस लेयर (news.db)
├── rewriter.py            # AI/NLP कंटेंट एनहांसर व सारांश जनरेटर
├── fetcher.py             # ऑटोमैटिक न्यूज़ फेचर इंजन
├── scheduler.py           # बैकग्राउंड ऑटोमेशन शेड्यूलर (हर 20 मिनट)
├── app.py                 # Flask वेब सर्वर एवं रूट्स
├── run.py                 # 1-क्लिक स्टार्टर स्क्रिप्ट
├── requirements.txt       # ज़रूरी लाइब्रेरीज़
├── static/
│   ├── css/style.css      # कस्टम स्टाइल और एनिमेशन
│   └── images/logo.svg    # PunjabState News का आधिकारिक लोगो
└── templates/
    ├── base.html          # मास्टर लेआउट (हेडर, टिकर, फुटर)
    ├── index.html         # होमपेज (लीड स्टोरीज़, ज़िला फ़िल्टर)
    ├── city.html          # ज़िला-विशिष्ट न्यूज़ पेज
    ├── category.html      # श्रेणी अनुसार न्यूज़ पेज
    ├── article.html       # सिंगल न्यूज़ रीडर पेज (Schema & Share)
    ├── search.html        # सर्च रिज़ल्ट पेज
    ├── admin.html         # एडमिन डैशबोर्ड
    ├── about.html         # हमारे बारे में (SEO जरूरी)
    └── contact.html       # संपर्क केंद्र (SEO जरूरी)
```
